Batch Migration Helper

The batch processor is deprecated in favor of exporter batching (sending_queue.batch). Paste a Collector configuration to see the equivalent. Everything runs in your browser. Nothing is uploaded.

    This mapping is inferred from the options' meaning and defaults. The migration guide does not list it field by field, so check the result against the migration guide. Processors, exporters and pipelines that can't be converted safely are left unchanged and explained above.

    Single YAML document only. Comments and key order are preserved where possible. Environment placeholders such as ${env:NAME} are copied as written.
